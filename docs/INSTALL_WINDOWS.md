# LINYUE Windows v0.5.67 安装与连接

1. 解压完整 ZIP，保留 `Windows` 文件夹中的所有文件和 `data` 文件夹，然后运行 `Windows/linyue.exe`。不要单独复制 EXE。
2. 两台电脑使用局域网连接时，请接入同一个可互访的专用网络。应用启动后会自动搜索一次；也可点首页刷新。首次出现 Windows 防火墙提示时，只允许“专用网络”访问。
3. 使用蓝牙时，先在两台电脑的 Windows 蓝牙设置中开启蓝牙并完成系统配对。双方都运行兼容版本的 LINYUE；接收端打开“连接设备 → 蓝牙连接”并点“等待另一台电脑连接”，发起端刷新设备并选择接收端。
4. 发现或系统配对不等于 LINYUE 身份认证。首次关联时，按应用提示在两端核对并确认身份码；未完成认证前不要发送文件。

如果局域网列表仍为空，请确认电脑连接到同一网段、网络配置文件为“专用”，且防火墙允许 LINYUE 在专用网络通信。访客 Wi-Fi、客户端隔离、跨 VLAN 或公司网络策略可能阻止设备互访。

蓝牙电脑间链路已包含在本构建中，但尚未完成两台实体 Windows 电脑的蓝牙硬件互连验收。当前包是 Debug 构建；蓝牙功能仅在 Debug 版本中开放。
