# LINYUE Android v0.5.68 安装与连接

本次 APK 是 `0.5.68+52` Debug 构建，保留现有蓝牙功能。安装后在设置页核对版本为 `v0.5.68`。

## 安装与保留数据

- 本轮用户提供的手机版本为 `v0.5.64 DEV13D2E37`。应用包名保持 `com.nearlink.nearlink`，不主动更换数据目录或设备身份。
- 维护电脑未找到旧版使用的 Android 调试签名文件。本轮构建签名与手机原应用的兼容性尚未确认，不能保证覆盖更新成功。
- 在手机上通过系统安装器尝试更新。如果提示签名冲突、应用未安装或要求卸载旧版，请停止，并保留旧应用及数据；需要找回原签名后重新构建。不要通过卸载或清除数据绕过。
- 本轮未连接 Android 真机，没有进行安装、升级或真实设备传输验收。

## 使用

1. 手机和电脑接入可互访的同一局域网，双方保持应用在前台。启动时会自动搜索，也可点首页刷新。Android 现在同样支持读取实际网卡前缀并执行有上限的私有子网搜索。
2. 局域网搜不到时，检查访客网络、客户端隔离或 Windows 防火墙，也可使用原有的手动 IP 连接。发现设备后仍需要完成身份核对和认证。
3. 蓝牙连接手机与 Windows 电脑时，先在系统设置完成配对。在手机允许“附近的设备”蓝牙连接权限并开启接收等待，再从电脑选择手机连接。
4. 大文件请使用局域网。蓝牙文件仍按双方协商限制，当前同版本最多 10 MiB；本轮没有增加蓝牙大文件或断点续传能力。

Android 大文件预检保留基于目标目录所在卷的 `StatFs` 可用空间查询。发送端需要空间制作可恢复副本，接收端也需要保留写入空间；不要仅根据原文件大小判断剩余空间是否足够。
